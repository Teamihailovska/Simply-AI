# AI-Concierge Website

Standalone React + Vite website concept for SimplyAI's AI-Concierge.

## Start

```bash
npm install
npm run dev
```

Then open the local Vite URL (usually http://localhost:5173/).

## Notes

- German is default; English toggle is included.
- Brand colors follow the supplied AI-Concierge material.
- `/public/ai-concierge-logo.svg` is the supplied AI-Concierge logo asset.
- Demo buttons point to `https://demo.simplyai.at`.
- Phone/address follow the supplied AI-Concierge PDF.
